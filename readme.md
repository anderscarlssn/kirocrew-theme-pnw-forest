# PNW Forest 🌲

A calm, vivid Pacific Northwest rainforest theme for Kiro Crew. Deep moss and fern greens throughout, with loader icons of firs, mountains, rain, crabs, salmon and sun.

## Install

Settings -> Display -> Install theme, then paste:

```
https://github.com/anderscarlssn/kirocrew-theme-pnw-forest
```

Icons from [Lucide](https://lucide.dev), [Lucide Lab](https://github.com/lucide-icons/lucide-lab) and [Tabler](https://tabler.io/icons). Licenses in LICENSE.txt.
